# Quick Start - Universal Kids App

## Easy Start Options

### 🐧 **Linux/Pop OS** (Recommended)
1. **Option 1 - Terminal (Easiest)**
   ```bash
   bash /home/popos/Desktop/games/android\ version/run-dev.sh
   ```
   Or just double-click `run-dev.sh`

2. **Option 2 - Desktop Launcher**
   - Double-click `launch-dev.desktop` 
   - Choose "Execute" when prompted

### 🪟 **Windows**
Double-click `run-dev.bat` to start the server

### 🍎 **macOS**
Double-click `run-dev.sh` to start the server

---

## What Happens When You Run It?

1. The dev server starts automatically
2. Opens at `http://localhost:5173`
3. You'll see: `VITE v5.4.21 ready in X ms`
4. Open your browser and navigate to `http://localhost:5173`
5. Swipe up on the lock screen to unlock

---

## Stop the Server

In the terminal window:
- Press `q + Enter` to quit
- Or close the terminal window

---

## If It Doesn't Work

Try running in terminal manually:
```bash
cd "/home/popos/Desktop/games/android version"
npm run dev
```
